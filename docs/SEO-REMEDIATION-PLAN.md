# knowlton.co.nz SEO remediation and /mi/ retirement
Date: 21 October 2026
Status: implementation handoff for Codex, NOT deployed
Primary repo: https://github.com/nknowlton/nknowlton.github.io (default branch `master`)

## Decision

Retire the un-translated `/mi/` website entirely. It currently reproduces the seven English lab pages as purported te reo Māori pages. Do **not** add interim canonicals to retain this mirror, and do **not** create a new translation. Remove routes, locale handling, hreflang/metadata, language-switcher code, and all sitemap references. Preserve all English pages and the four separately deployed course subsites.

Prefer permanent **301** redirects at Cloudflare for the seven retired URLs to their English equivalents, but do not block source removal on gaining Cloudflare configuration access. Cloudflare settings are outside these GitHub repositories and must be verified/configured separately. If redirects cannot be configured, let the deleted URLs return **404/410** rather than serving duplicate or generated stub content. Do not return 200 with English text at `/mi/`.

## Scope and verified architecture

- Root Astro site: `nknowlton/nknowlton.github.io`, Node >=22, Astro 5, Tailwind 4, GitHub Actions `.github/workflows/deploy.yml`, `dist/` deploy to GitHub Pages, Cloudflare in front.
- The mirror is generated by `src/pages/[locale]/index.astro` and `src/pages/[locale]/[slug].astro`, with `locales = ["en", "mi"]` in `src/data/site.ts` and linked from `src/lib/routing.ts`, `src/layouts/BaseLayout.astro`. `src/components/LanguageSwitcher.astro` exists but is not imported by the audited components.
- Course sites are separate repos and deployment artefacts: `nknowlton/161251` (main, R/Bookdown), `nknowlton/161324` (main, Bookdown/Quarto), `nknowlton/161762` (master, Quarto), `nknowlton/297101` (main, Quarto/R). Their public `/161251/`, `/161324/`, `/161762/`, `/297101/` paths are not source directories of the Astro hub. Preserve Cloudflare path routing and live course sites.
- Audit input: 60 sampled pages from 134 sitemap URLs on 21 Oct 2026. Missing canonicals, repeated headings, and metadata issues are concentrated in the separately built 161251 pages. Counts describe **the sampled deployment**, not the entire site.
- Audit caveats: `findings/content.md` contradicts `findings/technical.md` on the presence of canonicals. Trust actual source and freshly generated HTML, not either blanket claim. The proposed `ResearchGroup` schema type needs replacement with a recognised schema.org type such as `ResearchOrganization`, or ordinary `Organization` if that represents the lab more accurately.

## Codex execution rules

1. Work in small PRs, one repository at a time; do not merge or deploy automatically.
2. Inspect the current default branch, `AGENTS.md`, build workflow, existing tests, and changes since this plan before editing.
3. Make source/generator edits, not direct edits to generated `dist/`, `_site/`, `build/` or Bookdown HTML.
4. Do not change biomedical claims, student status, publications, course codes or availability language without source verification. Do not invent dates, authors, patents, performance claims or emails.
5. Avoid global find-and-replace for H1 or meta; preserve semantic headings and rendered lecture content.
6. Collect build evidence and relevant generated output for each PR.

## PR A (P0): retire /mi/ and repair hub metadata

Repository: `nknowlton/nknowlton.github.io`.

### A1. Remove the seven /mi/ pages at source
- Delete `src/pages/[locale]/index.astro` and `src/pages/[locale]/[slug].astro` (or refactor so no secondary static path is emitted).
- Simplify `src/data/site.ts`: remove `mi`, `secondaryLocales`, `localeNames`, duplicated `pageMeta[...].mi` data. Prefer straightforward English-only types/objects over a locale abstraction that supports just one language.
- Simplify `src/lib/routing.ts`: paths always point to English URLs. Remove `getAlternateLinks`; keep one canonical URL helper used consistently.
- Remove the unused `src/components/LanguageSwitcher.astro`; refactor `SiteHeader.astro`, `SiteFooter.astro`, `HomeView.astro`, `SectionPageView.astro`, `src/pages/index.astro`, `src/pages/[slug].astro` and `BaseLayout.astro` only as required to avoid orphan locale props/imports.

Preserve per-page self-canonicals.
- Ensure the sitemap integration generates **only seven hub routes**, not fourteen, while leaving course sitemaps declared in `public/robots.txt`. Never add `/mi/` to robots disallow as a substitute for proper removal.
- Update `README.md` to English-only routing, and remove locale descriptions that no longer apply.

### A2. Fix root discoverability
- Correct the homepage `<title>` in `BaseLayout.astro`/`src/data/site.ts` so it is not `Knowlton Lab | Knowlton Lab`. Target: `Knowlton Lab | Dr Nick Knowlton, Massey University`. Do not append the brand a second time.
- Use a unique, factual homepage description naming breast cancer research, biostatistics and reproductive AI. Update `og:title`, `og:description` and site JSON-LD consistently without overwriting existing visible content.
- Improve the extremely short publications description and the other hub page descriptions using the supplied `content.md` drafts as *proposals*, after confirming claims against current site text. Keep the publications list accurate and newest-to-oldest.
- In `src/data/sections.ts`, change the `161.777 Practical Data Mining` `resources` link from the `/161777/` meta-refresh stub to **`/161324/`**. **Keep the actual course code 161.777 and corresponding official Massey URL**, rather than relabelling the course 161.324 just because its reusable notes live under a legacy path. The legacy `public/161777/index.html` stub can remain as a compatibility path unless there is a reason to retire it separately.

### A3. Introduce /llms.txt carefully
- Add `public/llms.txt` (plural), concise human-readable Markdown describing Knowlton Lab, Dr Nicholas (Nick) Knowlton, Massey/Auckland affiliations, main research themes, and absolute HTTPS links for About, Research, Publications, People, Teaching, Join, and the four teaching subsites.
- Link verified Google Scholar, ORCID, university profiles; use English only. No invented findings, AI rankings, grant outcomes, or unverified impact metrics. The purpose is a lightweight machine-readable contents guide, not a guaranteed Google/ChatGPT ranking benefit.
- This is **optional SEO enhancement**, lower priority than identity, content, links, canonicals and sitemaps. Do not create duplicate `llm.txt` or a large auto-generated `llms-full.txt` without a demonstrated need.

### A4. Test the hub build
- `npm ci`

- Assert generated `dist/index.html`, six English pages, `dist/llms.txt`, `dist/sitemap-index.xml`, `dist/sitemap-0.xml`; assert `dist/mi/` absent.

### A5. Edge retirement (separate Cloudflare task)

`/mi/` → `/`; `/mi/about/` → `/about/`; `/mi/research/` → `/research/`; `/mi/students/` → `/students/`; `/mi/teaching/` → `/teaching/`; `/mi/publications/` → `/publications/`; `/mi/join/` → `/join/`.

## Release gates and acceptance criteria

**Gate A / hub:** successful Astro build; no `/mi/` generated artefacts or internal links, zero `mi-NZ` data, 7 hub entries in sitemaps (not 14), correct home title, `/llms.txt` 200 text/plain, valid English canonicals, all main English pages 200, all four teaching root URLs still resolve.

**Gate B / mirror lifecycle:** all 7 retired routes produce either Cloudflare 301 to their matching English pages (preferred) or verified 404/410; none are indexable 200 English duplicates; sitemap has no `/mi/`. Check redirect loops and `/mi` with/without slash.

**Gate C / course sites:** no 404 or speaker-view resources in sitemaps; no destroyed slide dependencies; one meaningful H1 on representative notes/labs; unique titles/descriptions and correct canonicals on audited samples; working lectures, labs, downloads and scripts.

**Gate D / claims/schema:** structured data parsed and semantically checked, no placeholder TODO values shipped, all quoted impact claims traceable to actual supporting evidence.
